CSS Box Sizing Example

1. Content Box

box-sizing: content-box
Width = 300px
Padding = 30px left + 30px right
Border = 10px left + 10px right
Actual width becomes: 300 + 60 + 20 = 380px

2. Border Box

box-sizing: border-box
Width = 300px
Padding and border are included inside the 300px width.

Actual width remains 300px.
Main Difference

content-box: Width and height apply only to the content. Padding and border are added outside.

border-box: Width and height include content, padding, and border.
